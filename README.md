# Machine Learning Practicals

## 📌 About the Project

This repository contains seven Machine Learning practicals implemented using Python and Jupyter Notebook. These practicals demonstrate important machine learning algorithms and techniques used for data analysis, classification, and model building.

## 🧪 List of Practicals

| **Sr. No.** | **Practical Name**           |
| ----------- | ---------------------------- |
| 1           | Logistic Regression          |
| 2           | K-Nearest Neighbors (KNN)    |
| 3           | Support Vector Machine (SVM) |
| 4           | Decision Tree                |
| 5           | Random Forest                |
| 6           | Gradient Descent             |
| 7           | Ensemble Techniques          |

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 🎯 Objectives

- Understand fundamental Machine Learning algorithms.
- Implement classification techniques using Python.
- Learn model training, prediction, and evaluation.
- Explore ensemble learning techniques.

## 🚀 How to Run

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   pip install numpy pandas matplotlib scikit-learn jupyter
4. Open Jupyter Notebook:

   jupyter notebook
5. Open any practical `.ipynb` file and run the cells.

## 📚 Learning Outcomes

These practicals provide hands-on experience with supervised learning algorithms, optimization methods, and ensemble learning.
